# Капсула времени

Одностраничный сайт: подарок под замком с обратным отсчётом. В назначенный момент замок открывается, и из коробки появляется голосовое послание.

- Дата открытия и имя аудиофайла задаются в начале `index.html` (`UNLOCK_AT`, `AUDIO_SRC`).
- Голосовое сообщение кладётся рядом как `message.mp3`.
- Посмотреть открытие заранее: добавить `?demo` к адресу.
